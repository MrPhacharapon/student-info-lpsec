# รหัสนักเรียน เลขประจำตัวประชาชน ชื่อ-สกุล (SET) วันเกิด / อายุ ประเภทความพิการ (SET) ที่อยู่ตามทะเบียนบ้าน สถานะ สรุปความแตกต่าง (Diff) จัดการ
ไม่พบรายการที่ตรงกับเงื่อนไขการค้นหา
นโยบายความปลอดภัยและการคุ้มครองข้อมูลส่วนบุคคล (Preview Mode): • เลขประจำตัวประชาชนและข้อมูลส่วนบุคคลทั้งหมดถูกประมวลผลภายในหน่วยความจำของเว็บเบราว์เซอร์เท่านั้น และจะถูก Masked สำหรับการแสดงผลปกติ • การแสดงผลนี้เป็นการจำลองเปรียบเทียบ (Preview) เท่านั้น ยังไม่มีการบันทึก ดัดแปลง หรือเขียนทับข้อมูลจริงใน Google Sheets • นักเรียนที่มีเฉพาะใน Google Sheets แต่ไม่พบในทะเบียน SET เป็นรายการที่รอผู้ดูแลระบบตรวจสอบ โดยระบบ Preview ยังไม่มีการซ่อนหรือลบข้อมูลจากเว็บไซต์จริง
